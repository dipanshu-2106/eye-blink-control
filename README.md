# Eye Blink Slide Control 👀

An AI-based computer vision project that allows you to control presentation slides using eye blinks.

## 🚀 Features
- 👁️ Single blink → Next slide
- 👁️ Double blink → Previous slide
- ⚡ Real-time face & eye tracking using MediaPipe
- 🎯 Hands-free presentation control

## 🛠️ Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- PyAutoGUI

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the program:
   python main.py

## 💡 Use Cases
